# hayabee29 - 年別ログ（自動同期Webアプリ）

2020年〜2035年までの年ごとの記録や予定をまとめて管理・閲覧できる、スマホ対応のシンプルなWebアプリケーションです。

## 🌟 主な機能

- **年別ログ表示**: 2020年から2035年までのカードが一覧で並び、各年の内容をスッキリ確認できます。
- **パスワード認証による保護**: 設定エリアはパスワード認証をクリアしないと編集できない安全仕様です。
- **自動保存 ＆ クラウド同期**: 
  - 入力した内容は自動で `localStorage` に保存され、オフラインでも動作します。
  - Google Apps Script（GAS）のAPIと連携し、クラウド側への自動保存・同期にも対応しています。
- **スマホ対応**: レスポンシブ対応に加え、iOSのホーム画面追加（Webアプリ風表示）にも対応しています。

## 🚀 使い方

1. ページを開くと、2020〜2035年の年別カード一覧が表示されます。
2. 画面下部のパスワードを入力して認証します。
3. 編集したい年を選んでテキストを入力すると、自動で保存・同期されます。
4. 基本ページを更新すると自動更新されます。
